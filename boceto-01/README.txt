MEDAL — Landing Page Boceto 01

1. Abre index.html en el navegador.
2. Para colocar tu video, agrega un archivo llamado:
   assets/medal-hero.mp4
3. El boceto funciona aunque todavía no agregues el video: usa un fondo fallback.
4. El logo está recreado provisionalmente con texto + símbolo vectorial simple para poder evaluar composición.
5. Cuando tengamos el logo oficial en SVG y el video definitivo, se reemplazan directamente.

Archivos:
- index.html
- styles.css
- script.js
- assets/poster.svg
- assets/medal-hero.mp4 (debes añadirlo)
